# Create and Remove Directories

## English
This section explains how to organize the filesystem by creating and removing directories.
- `mkdir name`: creates a new directory in the current working directory.
- `mkdir path/to/dir`: creates a directory at the specified path.
- `mkdir -p path/to/dir`: creates parent directories as needed, allowing nested directory creation in one command.
- `rmdir path/to/dir`: removes an empty directory only.
- `rmdir` fails if the directory contains files or subdirectories, so it is only suitable for empty directories.

## Español
Esta sección describe cómo organizar el sistema de archivos creando y eliminando directorios.
- `mkdir nombre`: crea un nuevo directorio en el directorio de trabajo actual.
- `mkdir ruta/a/directorio`: crea un directorio en la ruta especificada.
- `mkdir -p ruta/a/directorio`: crea los directorios padre necesarios, permitiendo crear directorios anidados en un solo comando.
- `rmdir ruta/a/directorio`: elimina un directorio vacío solamente.
- `rmdir` falla si el directorio contiene archivos o subdirectorios, por lo que solo sirve para directorios vacíos.
