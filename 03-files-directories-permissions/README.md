# Files, Directories and Permissions

This folder contains a set of learning notes about Linux files, directories, navigation, and permissions. Each markdown file is written as a short lesson or challenge that explains key command-line concepts in both English and Spanish.

## Index / Índice

- `01-linux-file-system.md` — Linux file system layout and common directories / Estructura del sistema de archivos de Linux y directorios comunes
- `02-file-paths.md` — Absolute and relative file paths / Rutas de archivos absolutas y relativas
- `03-navigating-file-system.md` — Navigating the file system with `cd` and directory shortcuts / Navegación por el sistema de archivos con `cd` y accesos directos de directorio
- `04-finding-directories-and-files.md` — Inspecting files and directories with `ls`, `file`, and `stat` / Inspección de archivos y directorios con `ls`, `file` y `stat`
- `05-create-remove-directories.md` — Creating and removing directories with `mkdir` and `rmdir` / Crear y eliminar directorios con `mkdir` y `rmdir`
- `06-copy-move-delete-files-and-directories.md` — Copying, moving, and deleting files and directories with `cp`, `mv`, and `rm` / Copiar, mover y eliminar archivos y directorios con `cp`, `mv` y `rm`
- `07-find-files-command-line.md` — Searching for files with the `find` command / Buscar archivos con el comando `find`
- `08-user-roles-and-sudo.md` — Linux user roles, the root account, and `sudo` privileges / Roles de usuario en Linux, la cuenta root y privilegios `sudo`
- `09-file-permissions.md` — File metadata and link concepts, including hard links and symbolic links / Metadatos de archivos y conceptos de enlaces, incluyendo enlaces duros y simbólicos
- `10-hard-and-symbolic links.md` — Differences between hard links and symbolic links, and how to create them / Diferencias entre enlaces duros y simbólicos y cómo crearlos
- `11-challenge-fix-sintax.md` — Command syntax challenge: identifying and fixing broken Linux commands / Desafío de sintaxis: identificar y corregir comandos de Linux rotos

## Summary / Resumen

### English
This directory covers the basics of working with file systems on Linux. It explains how the Linux file hierarchy is organized, how to use file paths, and how to move around directories. It also teaches how to inspect file details using common tools, how to create and remove directories, and how to manage files with copy, move, and delete commands. Additional lessons introduce file search with `find`, Linux user roles and `sudo`, and the differences between hard and symbolic links. The final file presents a practical syntax challenge that helps reinforce command structure and argument rules.

### Español
Este directorio cubre los conceptos básicos para trabajar con sistemas de archivos en Linux. Explica cómo está organizada la jerarquía de archivos en Linux, cómo usar rutas de archivos y cómo moverse entre directorios. También enseña cómo inspeccionar los detalles de archivos con herramientas comunes, cómo crear y eliminar directorios y cómo gestionar archivos con comandos de copiar, mover y eliminar. Las lecciones adicionales introducen la búsqueda de archivos con `find`, los roles de usuario en Linux y `sudo`, y las diferencias entre enlaces duros y simbólicos. El archivo final presenta un desafío práctico de sintaxis que ayuda a reforzar la estructura de comandos y las reglas de argumentos.
