# Linux File System

## English
The Linux file system hierarchy and its organization are described, comparing files and directories to the graphical environment and introducing command line navigation. The file system starts at root (`/`), which is the top-level directory where all other files and folders live. Important standard directories include:

- `/home`: user personal files and directories
- `/root`: home directory for the root user
- `/etc`: system and application configuration files
- `/bin` and `/sbin`: essential system programs and binaries
- `/lib`: shared libraries and modules
- `/mnt` and `/media`: mount points for additional or removable filesystems
- `/dev`: hardware device references
- `/proc`: process and system information
- `/sys`: kernel parameters and system details

It emphasizes that users usually work in their own home directory and that exploring system directories is safe for normal users because write permissions are limited. Understanding these locations is useful for Linux administration and software development.

## Español
Se describe la jerarquía del sistema de archivos de Linux y cómo está organizada. Compara archivos y directorios con el entorno gráfico y presenta la navegación a través de la línea de comandos. El sistema de archivos comienza en la raíz (`/`), que es el directorio de nivel superior donde residen todos los demás archivos y carpetas. Los directorios estándar más importantes incluyen:

- `/home`: archivos y directorios personales de los usuarios
- `/root`: directorio personal del usuario root
- `/etc`: archivos de configuración del sistema y aplicaciones
- `/bin` y `/sbin`: programas y binarios esenciales del sistema
- `/lib`: bibliotecas compartidas y módulos
- `/mnt` y `/media`: puntos de montaje para sistemas de archivos adicionales o extraíbles
- `/dev`: referencias a dispositivos de hardware
- `/proc`: información sobre procesos y el sistema
- `/sys`: parámetros del kernel y detalles del sistema

Se enfatiza que los usuarios suelen trabajar en su propio directorio home y que explorar directorios del sistema es seguro para un usuario normal porque los permisos de escritura son limitados. Comprender estas ubicaciones es útil para la administración de Linux y el desarrollo de software.
