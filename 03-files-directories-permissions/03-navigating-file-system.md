# Navigating the File System

## English
Terminal navigation uses commands to move through directories and verify the current location. The `cd` command changes the current working directory, and `pwd` prints the working directory. Paths can be absolute or relative:

- Relative navigation uses names like `Documents` from the current directory.
- `..` moves up to the parent directory.
- `cd -` switches back to the previous directory.
- `cd` with no arguments returns to the user's home directory.

Tab completion helps type directory names faster. The `ls` command lists directory contents, and `ls -R` lists contents recursively across nested directories. These tools allow users to explore the filesystem structure and move between directories where they have access.

## Español
La navegación por terminal utiliza comandos para desplazarse entre directorios y verificar la ubicación actual. El comando `cd` cambia el directorio de trabajo actual, y `pwd` muestra el directorio de trabajo. Las rutas pueden ser absolutas o relativas:

- La navegación relativa usa nombres como `Documents` desde el directorio actual.
- `..` sube al directorio padre.
- `cd -` vuelve al directorio anterior.
- `cd` sin argumentos regresa al directorio home del usuario.

La autocompletación con Tab ayuda a escribir nombres de directorio más rápido. El comando `ls` muestra el contenido de los directorios, y `ls -R` muestra el contenido de forma recursiva en directorios anidados. Estas herramientas permiten explorar la estructura del sistema de archivos y moverse entre directorios con acceso permitido.
