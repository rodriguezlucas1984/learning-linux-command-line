# Understand how commands are structured

## English
A command line statement follows a clear pattern: command, options, and arguments. The command is the program or action being requested. Options modify how the command behaves and often begin with a single dash (`-`) or double dash (`--`). Arguments specify the target of the command, such as files, paths, or text values. Common Linux commands like `ls`, `du`, `cat`, `df`, and `grep` use this structure, and options can often be combined for compact usage.

## Español
Una instrucción de línea de comandos sigue un patrón claro: comando, opciones y argumentos. El comando es el programa o la acción solicitada. Las opciones modifican el comportamiento del comando y suelen comenzar con un guion simple (`-`) o doble (`--`). Los argumentos indican el objetivo del comando, como archivos, rutas o valores de texto. Comandos comunes de Linux como `ls`, `du`, `cat`, `df` y `grep` usan esta estructura, y las opciones a menudo pueden combinarse para un uso más compacto.
