# What is the command line?

## English
The command line is a text-based interface used to interact with programs and the operating system by typing commands. On Linux, command-line workflows are common for system administration, development, and data analysis. A shell such as Bash interprets commands, and users often run it inside a terminal emulator or console. Command-line programs can read from and write to files, pass data between tools, and operate without a graphical interface.

## Español
La línea de comandos es una interfaz de texto para interactuar con programas y el sistema operativo mediante comandos escritos. En Linux, el uso de la línea de comandos es común para administración del sistema, desarrollo y análisis de datos. Un shell como Bash interpreta los comandos, y normalmente se usa dentro de un emulador de terminal o consola. Los programas de línea de comandos pueden leer y escribir archivos, pasar datos entre herramientas y funcionar sin una interfaz gráfica.
