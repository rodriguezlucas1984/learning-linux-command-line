# Write commands in a shell at the prompt

## English
Commands are entered at the shell prompt in a terminal. The shell interprets each command, runs the matching program, and displays the result. A prompt typically shows the current user, host, and working directory. Single commands like `ls` list files, while options such as `-l` change the output format. Command names must be spelled correctly, and incorrect commands return an error with no harm done. Many commands are standard GNU coreutils programs, while some are shell keywords.

## Español
Los comandos se ingresan en el prompt del shell en un emulador de terminal. El shell interpreta cada comando, ejecuta el programa correspondiente y muestra el resultado. Un prompt normalmente muestra el usuario actual, el nombre del equipo y el directorio de trabajo. Comandos básicos como `ls` enumeran archivos, y opciones como `-l` modifican el formato de salida. Los nombres de comandos deben escribirse correctamente; un comando no encontrado devuelve un error sin causar daños. Muchos comandos son programas estándar de GNU coreutils, y algunos son comandos integrados del shell.
