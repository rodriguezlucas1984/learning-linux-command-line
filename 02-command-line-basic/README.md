# Command Line Basics

## English
This directory contains introductory materials for using the Linux command line. The lessons focus on how commands are structured, how to run them, how to get help, and how to use keyboard shortcuts efficiently.

### Index of Markdown Files
- [01-intro-cli.md](01-intro-cli.md) — Introduction to the command line and its role in Linux.
- [02-command-structure.md](02-command-structure.md) — Explanation of command structure using commands, options, and arguments.
- [03-running-commands.md](03-running-commands.md) — Basics of entering and executing commands in a shell prompt.
- [04-getting-help.md](04-getting-help.md) — How to use manual pages, help flags, and search tools like `apropos`.
- [05-keyboard-shortcuts.md](05-keyboard-shortcuts.md) — Useful terminal shortcuts for faster navigation and editing.
- [06-challenge-command-info.md](06-challenge-command-info.md) — Practice exercise about finding command-related information.

### Summary
These files provide a practical introduction to working with the Linux terminal. Together, they help learners become more comfortable with basic command usage, documentation, and everyday terminal shortcuts.

## Español
Este directorio contiene materiales introductorios para usar la línea de comandos de Linux. Las lecciones se enfocan en cómo se estructuran los comandos, cómo ejecutarlos, cómo obtener ayuda y cómo usar atajos de teclado de manera eficiente.

### Índice de archivos Markdown
- [01-intro-cli.md](01-intro-cli.md) — Introducción a la línea de comandos y su papel en Linux.
- [02-command-structure.md](02-command-structure.md) — Explicación de la estructura de los comandos mediante comandos, opciones y argumentos.
- [03-running-commands.md](03-running-commands.md) — Conceptos básicos para ingresar y ejecutar comandos en el prompt del shell.
- [04-getting-help.md](04-getting-help.md) — Cómo usar páginas de manual, opciones de ayuda y herramientas como `apropos`.
- [05-keyboard-shortcuts.md](05-keyboard-shortcuts.md) — Atajos útiles del terminal para una navegación y edición más rápidas.
- [06-challenge-command-info.md](06-challenge-command-info.md) — Ejercicio práctico sobre cómo encontrar información relacionada con comandos.

### Resumen
Estos archivos ofrecen una introducción práctica al trabajo con la terminal de Linux. En conjunto, ayudan a los estudiantes a sentirse más cómodos con el uso básico de comandos, la documentación y los atajos habituales del terminal.
