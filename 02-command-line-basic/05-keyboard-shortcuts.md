# Helpful keyboard shortcuts in the terminal

## English
Bash provides keyboard shortcuts that speed up editing and navigating command lines. Tab completion fills file names, directory names, and command names automatically. `Ctrl+C` cancels the current command, while arrow keys move the cursor. `Ctrl+A` and `Ctrl+E` jump to the beginning and end of the line. `Ctrl+Left`/`Ctrl+Right` move by words, while `Ctrl+U` and `Ctrl+K` delete text to the start or end of the line. Use `Ctrl+Shift+C` and `Ctrl+Shift+V` for copy and paste in the terminal. The up/down arrows recall previous commands, and `Ctrl+R` searches command history.

## Español
Bash ofrece atajos de teclado que aceleran la edición y la navegación de comandos. La completación con Tab rellena nombres de archivos, directorios y comandos automáticamente. `Ctrl+C` cancela el comando actual, mientras que las flechas mueven el cursor. `Ctrl+A` y `Ctrl+E` saltan al inicio y al final de la línea. `Ctrl+Izquierda`/`Ctrl+Derecha` avanzan palabra por palabra, y `Ctrl+U` y `Ctrl+K` borran texto hasta el inicio o el final de la línea. Usa `Ctrl+Shift+C` y `Ctrl+Shift+V` para copiar y pegar en el terminal. Las flechas arriba/abajo recuperan comandos previos, y `Ctrl+R` busca en el historial de comandos.
