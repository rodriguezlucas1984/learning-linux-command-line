- **Save & exit:** `Ctrl-O` write out (save), press Enter to confirm filename; `Ctrl-X` exit (prompts to save if modified).
- **Navigation:** Arrow keys move cursor; `Ctrl-A` go to line start, `Ctrl-E` go to line end; `Ctrl-V` page down, `Ctrl-Y` page up.

**Español — Conceptos y Comandos**

- **Nano:** Editor ligero y fácil de usar en terminal. Inicia con `nano` o `nano nombre_de_archivo`.
- **Ayuda en pantalla:** Los atajos aparecen abajo; el carácter caret `^` representa la tecla Control (Ctrl).
- **Guardar y salir:** `Ctrl-O` guardar (escribir), Enter para confirmar el nombre; `Ctrl-X` salir (pide guardar si hay cambios).
- **Navegación:** Flechas para mover el cursor; `Ctrl-A` inicio de línea, `Ctrl-E` fin de línea; `Ctrl-V` bajar página, `Ctrl-Y` subir página.
- **Operaciones de edición:** `Ctrl-K` cortar línea, `Ctrl-U` pegar (deshacer corte), `Ctrl-W` buscar, `Ctrl-G` ayuda.
- **Archivos:** Abrir un archivo existente con `nano nombre_de_archivo`; instala Nano si no está disponible.
