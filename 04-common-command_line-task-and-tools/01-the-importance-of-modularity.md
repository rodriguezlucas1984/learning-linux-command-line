# The importance of modularity

## English
How command line utilities work best when each tool performs a single task well. Highlights using text from files or streams, combining dedicated programs in pipelines, and applying filters, duplicate removal, and file output as separate steps.

## Español
Cómo las utilidades de línea de comandos funcionan mejor cuando cada herramienta realiza una sola tarea bien. Destaca el uso de texto desde archivos o flujos, la combinación de programas dedicados en canalizaciones y la aplicación de filtros, eliminación de duplicados y salida a archivos como pasos separados.

## Key concepts
- Single-purpose command line tools
- Standard input/output and file handling
- Pipeline composition
- Text filtering and removing duplicates
- Writing results back to files

## Conceptos clave
- Herramientas de línea de comandos de propósito único
- Entrada/salida estándar y manejo de archivos
- Composición en canalizaciones
- Filtrado de texto y eliminación de duplicados
- Escritura de resultados en archivos
