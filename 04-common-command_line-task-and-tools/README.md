# README — Common Command Line Tasks and Tools

## English

### Overview
This directory contains a practical set of lessons and exercises about everyday Linux command-line work. It introduces core ideas such as command composition, file navigation, text processing, editing, archiving, redirection, environment variables, and problem-solving challenges.

### Index of Markdown Files
- [01-the-importance-of-modularity.md](01-the-importance-of-modularity.md) — Explains why small, single-purpose command-line tools work well together and how pipelines combine them.
- [02-pipes.md](02-pipes.md) — Covers pipes and command chaining to transform data step by step.
- [03-navigating-the-file-system.md](03-navigating-the-file-system.md) — Teaches how to move around directories and use paths effectively.
- [04-finding-directory-and-file-information.md](04-finding-directory-and-file-information.md) — Shows how to inspect directories, files, permissions, and metadata.
- [05-manipulate-text-with-awk-sed-and-sort.md](05-manipulate-text-with-awk-sed-and-sort.md) — Introduces text processing with awk, sed, and sort.
- [06-edit-text-with-vim.md](06-edit-text-with-vim.md) — Explains basic Vim commands for editing files in the terminal.
- [07-edit-text-with-nano.md](07-edit-text-with-nano.md) — Covers Nano as a simple and friendly terminal editor.
- [08-working-with-tar-and-zip-archives.md](08-working-with-tar-and-zip-archives.md) — Demonstrates how to create and extract archive files.
- [09-challenge-create-and-share-file.md](09-challenge-create-and-share-file.md) — Presents a hands-on challenge about creating, sharing, and compressing a file.
- [10-output-redirection.md](10-output-redirection.md) — Explains how to redirect standard input, output, and error streams.
- [11-exploring-enviroment-variables-and-path.md](11-exploring-enviroment-variables-and-path.md) — Introduces environment variables and the PATH variable.
- [12-extract-information-challenge.md](12-extract-information-challenge.md) — Describes a challenge to extract information from a compressed log archive.

### Directory Summary
The folder mixes theory, command examples, and practical exercises. It is designed to help learners build confidence with common shell tasks and understand how Linux tools can be combined effectively.

## Español

### Resumen General
Este directorio contiene una serie práctica de lecciones y ejercicios sobre tareas comunes de la línea de comandos en Linux. Presenta ideas clave como la composición de comandos, la navegación por archivos, el procesamiento de texto, la edición, la compresión, la redirección, las variables de entorno y desafíos de resolución de problemas.

- [03-navigating-the-file-system.md](03-navigating-the-file-system.md) — Enseña a moverse por directorios y a usar rutas de forma efectiva.

### Resumen del Directorio
La carpeta combina teoría, ejemplos de comandos y ejercicios prácticos. Está pensada para ayudar a los estudiantes a ganar confianza con tareas habituales del shell y a entender cómo combinar herramientas de Linux de manera eficiente.
