# Navigating the file system / Navegación del sistema de archivos

## English — Key commands & concepts
- `cd`: change directory; use `cd` alone to return to the home directory (`~`).
- `pwd`: print working directory — shows your current path.
- `ls`: list directory contents. `ls -R` lists recursively through subdirectories.
- `cd ..`: move to the parent directory; chain `..` to move up multiple levels (e.g., `cd ../../finance/documents`).
- `cd -`: switch back to the previous directory.
- Paths: `~` denotes the home directory; use relative paths (from current dir) or absolute paths from `/`.
- Shell conveniences: tab completion to auto-complete names; the shell prompt often shows the current directory.

## Español — Comandos y conceptos clave
- `cd`: cambiar de directorio; `cd` sin argumentos vuelve al directorio personal (`~`).
- `pwd`: muestra el directorio de trabajo actual.
- `ls`: lista contenidos de un directorio. `ls -R` lista recursivamente los subdirectorios.
- `cd ..`: sube al directorio padre; encadenar `..` para subir varios niveles (p. ej. `cd ../../finance/documents`).
- `cd -`: vuelve al directorio anterior.
- Rutas: `~` indica el directorio personal; usar rutas relativas (desde el directorio actual) o rutas absolutas desde `/`.
- Utilidades del shell: completado con `Tab` para autocompletar nombres; el prompt suele mostrar el directorio actual.

## Focused usage tips / Consejos prácticos
- Use `pwd` to confirm your location before running commands that affect files.
- Use `ls -R` for a quick overview of nested folder contents.
- Use `cd -` to toggle between two directories when moving files or checking locations.
